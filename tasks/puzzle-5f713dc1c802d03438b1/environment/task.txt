# Puzzle task details

Find the smallest nonnegative integer `x` with `x < m` such that:

```text
(a * x + b) mod m = target
```

The instance values are:

- `a = 29`
- `b = 7`
- `m = 1013`
- `target = 775`

Submit the answer with `puzzlectl submit <x>`. A successful submission writes
the returned flag to `/workspace/flag.txt`.
